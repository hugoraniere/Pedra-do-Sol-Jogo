# Reino de Aurora

Jogo de aventura top-down feito para o Lele, 7 anos, a partir do RPG de mesa
que a gente criou no papel. Roda no navegador, funciona no iPad e no celular.

## Rodar

```bash
npm install
npm run dev
```

Abre em http://localhost:5173

## Comandos

| Comando | O que faz |
|---|---|
| `npm run dev` | servidor de desenvolvimento com recarga automatica |
| `npm run build` | checa os tipos e gera a versao final em `dist/` |
| `npm run preview` | serve a versao final para testar |
| `npm run arte` | regera toda a pixel art em `public/assets` |

Para gerar a arte e preciso Python 3 com Pillow: `pip install Pillow`

## Como jogar

Setas ou WASD para andar, espaco ou enter para falar e usar.
No toque, o direcional fica no canto de baixo a esquerda e o botao A no canto direito.
