# Sprites desenhados a mao

PNG colocado aqui substitui a versao gerada por codigo, se o nome bater.
Depois de colocar o arquivo, rode `npm run arte`.

Tamanhos: tile 16x16, personagem 16x24, icone de interface 16x16.
Paleta: `arte/paleta.py`. Importe ela na sua ferramenta de desenho antes de comecar.

Exemplos de nome: `tile-grama.png`, `tile-telhado.png`, `tile-copa.png`.
A lista completa de tiles esta em `TILES`, no fim de `arte/gerar.py`.

Ferramentas gratuitas: Pixelorama, LibreSprite, Piskel, Lospec Pixel Editor.
Detalhes em `docs/06-fluxo-de-sprites.md`.
